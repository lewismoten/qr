El texto del marco forma parte visible de la imagen exportada. Puede explicar para qué sirve un código, distinguir varios códigos impresos o mostrar una instrucción útil como «Llamar», «Enviar SMS» o «Conectarse a Wi-Fi».

Automático genera una etiqueta breve y sin información confidencial a partir del contenido seleccionado. Personalizado utiliza su mensaje, y Ninguno mantiene la imagen lo más compacta posible.

Frame message
Font

The message is embedded below the QR or given a tight contrasting outline when centered. Auto uses a concise, non-secret URL, phone number, email address, network name, contact, or file name.

Posición, tipografía y lectura

El texto situado debajo de la matriz no cubre módulos QR. El texto centrado utiliza un contorno de contraste en lugar de un cuadro sólido, pero aun así modifica módulos útiles y debe probarse con varios lectores. El control de altura de línea limita el espacio vertical mientras el renderizador ajusta el texto al mayor tamaño práctico dentro del ancho disponible.

Mantenga los rótulos breves y no incluya contraseñas ni otros datos confidenciales en el texto del marco: a diferencia de los datos codificados, cualquier persona que vea la imagen puede leer el mensaje de inmediato.
