Crear varios códigos desde un archivo CSV

La importación masiva lee un código QR por cada fila no vacía del archivo CSV. La primera fila nombra los campos del formato de contenido seleccionado. Las columnas sin nombre y sus valores se ignoran, al igual que las filas completamente vacías.

Bulk Import

File format is unavailable in Bulk Import. Use the dedicated File format for binary data.

url

Required values: url

No file selected

No se ha cargado ningún CSV.

Encabezados y validación

Los campos esperados y obligatorios cambian según el formato seleccionado. Las filas se validan antes de exportarlas; los archivos mal formados, demasiado grandes o con una estructura inesperada se rechazan con un mensaje claro. Para transferir archivos binarios se utiliza el formato específico de archivos.
