Preparar códigos QR para imprimir

La exportación PDF asigna un ancho físico a cada código QR en lugar de depender únicamente de los píxeles de pantalla. El tamaño automático tiene en cuenta el ancho renderizado y la versión QR para que cada módulo mantenga un tamaño adecuado después de imprimirlo.

PDF document

Auto print width uses 192 pixels per inch and protects higher-version QR modules from becoming too small. PDF sheets fit as many codes as the selected physical width allows.

Documentos de un solo y varios códigos

Descargar crea un PDF con el código QR visible. Descargar todo distribuye todos los códigos generados en una o varias hojas con el ancho de impresión seleccionado, lo que resulta útil para rangos, datos masivos y transferencias de archivos por fragmentos.
