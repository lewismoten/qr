02 / Metadata

The decoder receives instructions before content

Format and version information are encoded with BCH error protection. Format information is written twice so damage near one finder does not remove the decoder instructions.

EC level, mask and format protection

The 15-bit format value contains 2 error-correction-level bits and 3 mask-pattern bits. Ten BCH protection bits are appended, then the result is XOR-masked with a fixed pattern. The same value appears in two locations.

Version information

Versions 7 through 40 store an 18-bit protected version value in two 3-by-6 areas. Smaller versions communicate their size directly through matrix dimensions.
