Privacy and data use

How this site handles your information

Open generator

The QR Code Generator is designed to do its work in your browser. It has no user accounts, advertising, behavioral analytics or application database, and it does not intentionally upload the content you enter or the files you select to its own server.

Last updated: July 17, 2026

Information stored in your browser

The application uses local storage for one preference: qr.locale records the language you select, including the translation-debug language. Local storage persists across browser sessions for this site until you clear site data or choose another language. If storage is blocked or unavailable, the site still works but the preference may not persist.

The application reads the browser's preferred language list to choose and prioritize available translations. It does not submit that complete list as form or analytics data. When hosted over HTTP or HTTPS, it requests the selected same-origin language JSON file; as with any requested path, that locale filename may appear in ordinary server logs and can indicate the selected or matched language.

QR inputs, passwords, selected files, generated images, temporary object URLs, map position and other working state remain in browser memory. They are not intentionally written to local storage, session storage, IndexedDB or a service-worker cache by this application. Reloading or closing the page normally clears that working state.

Cookies and tracking

The application code does not set, read or require cookies. It does not include advertising pixels, social-media trackers or third-party analytics. The static hosting provider, reverse proxy, security service or network operator may independently add headers or use operational controls outside this repository; your browser's developer tools and site-data controls show what a particular deployment actually receives.

QR content and files

Text, URLs, contact details, Wi-Fi passwords, calendar events, geographic coordinates, artwork and files are processed locally with browser APIs. Downloads are assembled locally. Blob URLs are temporary references within the current browser session, while data URLs and the custom FILE:1 format place file information into the generated QR payload itself.

Anyone who can view or scan a QR code can potentially read its payload. Do not place secrets in a QR code unless you understand how it will be displayed, shared and stored. Hiding a password in the on-screen payload preview does not encrypt the generated QR code.

Server and network logs

Like most websites, the web server, hosting provider, content-delivery network, firewall or reverse proxy may record basic request information. Logs can include your public IP address, request date and time, requested path, response status, transferred bytes, browser user-agent, referrer and diagnostic or security information. These records may be used to operate, secure and troubleshoot the site. Their exact contents and retention depend on the production hosting configuration rather than the browser application code.

The included local development server serves static files and does not intentionally create request-log files or set cookies. That does not control logging performed by an operating system, network, proxy or production host.

Third-party requests

OpenStreetMap map tiles

Only after opening Geo

Opening the Geo format loads visible raster map tiles from tile.openstreetmap.org. When the generator is hosted over HTTP or HTTPS, tile requests include the site's origin in the Referer request header as required by the tile policy. OpenStreetMap's infrastructure also receives normal request information such as your IP address, browser headers and the tile coordinates requested, which can indicate the approximate map area being viewed. The QR application does not contact OpenStreetMap before the Geo interface is opened.

External links

Only when selected

Documentation links can take you to standards organizations, repositories and other websites. Those sites receive your IP address and ordinary browser request information when you open them and apply their own privacy practices. External links open in a new tab with noopener and noreferrer protections.

Same-origin resources and browser features

Application scripts, styles, language JSON files, About, Privacy, Technology and QR specification content are loaded from the same site. Browser features such as Canvas, Web Crypto, Compression Streams, MediaRecorder, file selection and local downloads operate on the device; using those APIs does not by itself send their contents to this site's server.

When index.html is opened directly from a filesystem with a file: URL, browser security rules generally prevent the language JSON requests. The application then uses embedded English labels and JavaScript fallback text. QR generation remains available, but non-English localization and restoration of a saved language may not work reliably until the files are served over HTTP or HTTPS.

Your choices

You can clear the saved language through your browser's site-data settings, block local storage, avoid opening Geo, avoid external links, or use the application from a locally served or downloaded copy. Browser privacy controls, extensions, firewalls and network settings may provide additional control over requests.

Questions or corrections can be raised through the project source repository.
