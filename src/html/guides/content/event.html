Put an event on a calendar

Calendar QR codes encode an iCalendar event with a title, start and end, optional location, description, and website. Compatible scanners can offer to add the event directly to a calendar.

Calendar event

Timed events use the scanner's local time zone. For all-day events, the selected end date is treated as the last included day.

Dates and local time

Timed events use the scanner's local time zone. All-day events omit times and include the selected end date as the final day. Verify event details before distributing a printed code.

Event website URLs and URL-format content are checked for common tracking parameters. When any are found, the generator identifies them and offers to remove them while preserving other query parameters and the URL fragment.
