Identify a QR code without scanning it

A frame message is visible text rendered as part of the exported image. It can tell someone what a code does, distinguish printed codes from one another, or provide a useful instruction such as “Call,” “Text,” or “Join Wi-Fi.”

Auto derives a short, non-secret label from the selected content. Custom uses your message, and None preserves the most compact image.

Frame message
Font

The message is embedded below the QR or given a tight contrasting outline when centered. Auto uses a concise, non-secret URL, phone number, email address, network name, contact, or file name.

Placement, typography, and scanning

Text below the matrix does not cover QR modules. Centered text uses a contrasting outline rather than a solid box, but it still changes useful modules and should be tested with several scanners. The line-height control limits vertical space while the renderer fits the largest practical text across the width.

Keep labels concise and avoid placing passwords or other secrets in frame text: unlike encoded payload data, the message is immediately readable by anyone who sees the image.
