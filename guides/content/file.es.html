Las URL de datos incluyen un archivo pequeño en un solo código QR. Las URL de tipo blob hacen referencia a la memoria del navegador y, por lo general, solo funcionan en el navegador que las creó. La transferencia por fragmentos divide los archivos más grandes en un conjunto ordenado y verificable de códigos QR.

El protocolo FILE identifica cada transferencia y cada intervalo de bytes.
